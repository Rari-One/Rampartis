# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue.

- **Email:** dev.rarione@pm.me

Please include the Rampartis version, your Windows version, and clear steps
to reproduce the problem. Leave out backup contents, credentials, and
private files. A description or a redacted example is enough.

## What to expect

Reports are reviewed and addressed as circumstances permit.

## Scope

This policy covers the Rampartis application. Issues in third-party
components are best reported to their own projects as well.
