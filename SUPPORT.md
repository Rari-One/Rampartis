# Support

## Getting help

- **Email:** dev.rarione@pm.me — monitored by the developer.
- **GitHub Issues**, when available: for general problem reports and questions.

## Before you write

Including these details helps: the Rampartis version (Settings shows it),
your Windows version, what you were doing, and the exact message the app
showed. Screenshots of the app's own messages are welcome after reviewing
them for private information.

For a network backup issue, say whether you used a direct UNC path.
If Rampartis offers **Export network backup diagnostics**, review the local
export before sharing it. The app does not upload it automatically.

## Please don't

- Keep backup contents, credentials, and private file paths out of reports.
  A description or a redacted example is usually enough.
- Don't post security vulnerabilities publicly — see
  [SECURITY.md](SECURITY.md) for the private route.
